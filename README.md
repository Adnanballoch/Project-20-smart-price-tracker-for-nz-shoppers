# Project 20: Smart Price Tracker for NZ Shoppers

**Category:** Consumer / AI
**Part of:** AutoMatrixLab

## Overview

An intelligent shopping companion that tracks live product prices across New Zealand e-commerce sites and sends real-time WhatsApp alerts when target prices are reached.

## Tech Stack

Python, BeautifulSoup, Twilio, Streamlit
